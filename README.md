# CrabitatCombo
## Introduction:
Crabitat Combo is a 2-5 player party game where players rush to create card combos,
expand their aquariums, and adopt new hermit crabs. But that's not all, Hermit Crab
Actions and Ability Cards add an exciting twist into every moment. You can disrupt
your opponents' turns, and manipulate the cards in play to outshine your fellow Hermit
Crab enthusiasts.

Among our fun party game mechanics lies a game that can teach and inspire people to
research and participate in proper hermit crab care.

## Features:
This project is creating a digital version of the physical card game that will eventually
be playable on Steam.

## Technologies:
This project is being created with the Godot engine using GDScript.

## Installation:
This will eventually be installed from Steam once the user has purchased the game.
